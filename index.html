    03 How it measures, and its limits

    • Integrated loudness: K-weighting and gating per ITU-R BS.1770-4. Passes the EBU Tech 3341 test cases and matches ffmpeg's ebur128 to 0.1 LU on every case in the benchmark.
    • Loudness range per EBU Tech 3342. Momentary and short-term maxima per EBU R128.
    • True peak is an estimate: 8x oversampling with a 256-tap interpolator. On the benchmark it reads within 0.1 dB of a much finer reference, except on heavily clipped audio where it can read up to about 0.4 dB high.
    • Non-WAV files are decoded by your browser and resampled to 48 kHz, which can shift true peak slightly. Lossy files already carry encoder changes.
    • Platform behaviour changes and listeners can switch normalisation off. Treat the table as a guide, not a guarantee.
    • Mono files are measured as one channel, as BS.1770 specifies. Some tools treat mono as dual mono, which reads about 3 LU louder.
